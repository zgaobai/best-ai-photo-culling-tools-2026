## How to compare tools

1. Use the same representative folder in every tool.
2. Include bursts, group portraits, difficult light, and known keepers.
3. Compare missed keepers and manual corrections, not just shortlist size.
4. Check privacy, file support, and the destination for exported files.
5. Compare the whole workflow cost, including editing credits.
